# Creator Prepublish QA

Gerbang terakhir sebelum supervisor menekan UPLOAD. Outputnya adalah verdict
jelas beserta daftar periksa yang bisa dicentang manusia dalam 2 menit.

## Ringkasan aturan

- Periksa segitiga janji: judul, thumbnail, dan 30 detik pertama harus menjanjikan hal yang sama dan dibayar isi.
- Metadata lolos aturan creator-seo-metadata (panjang, tanpa < >, tags relevan) dan fact-check tidak menyisakan klaim SALAH.
- File hasil ada di folder media KRA dengan nama final; visibilitas default Private kecuali ada alasan tertulis.
- Akhiri dengan verdict SIAP UPLOAD atau BELUM + daftar perbaikan bernomor; keputusan akhir tetap manusia.

## Daftar periksa

1. Judul/thumbnail/hook konsisten dan jujur.
2. Tidak ada klaim SALAH/MERAGUKAN tanpa label.
3. Musik/footage berlisensi atau bebas hak cipta.
4. Deskripsi memuat sumber + disclosure sponsor bila ada.
5. File + thumbnail berada di folder media; nama file final.
6. Visibilitas & made-for-kids sudah diputuskan sadar.

## Larangan

- Memberi verdict SIAP bila ada item BLOKIR dari creator-policy-guard.
- Mengubah keputusan manusia — skill ini menyarankan, supervisor memutuskan.
