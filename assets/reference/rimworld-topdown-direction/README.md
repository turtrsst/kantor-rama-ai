# North-up top-down style references

These four user-provided screenshots are retained as visual direction only. They inform square-grid room layout, room-cutaway walls, overhead props, muted floor tiles, and soft contact shadows. They are not copied into the game as textures.

- `rimworld-office-rooms.png`
- `rimworld-colony-interior-wide.png`
- `topdown-kitchen-reference.png`
- `topdown-utility-reference.png`

The implementation uses KRA's existing office atlas and crew sprites. Official RimWorld textures were not extracted or redistributed; see the Ludeon FAQ in `docs/COLONY_LAYOUT_REFRESH.md` for the asset-policy reference.
